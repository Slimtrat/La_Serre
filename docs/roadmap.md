# Roadmap

1. **One Complete Shot** — tranche actuelle.
2. **One Complete Episode** — moteur et CLI livrés : voix locales ou importées,
   clips approuvés, mixage, sous-titres et montage FFmpeg vérifié. Raccord du
   graphe Studio à effectuer sur les nœuds déjà réservés.
3. **Three Consistent Episodes** — références stables, continuité visuelle et
   timeline canonique.
4. World state, moteur narratif, puis studio React seulement après validation
   des trois épisodes.
